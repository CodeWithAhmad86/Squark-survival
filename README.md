# 🏕️ Squark Survival

**A 3D survival game built with Three.js.**

Welcome to **Squark Survival**! Explore the world, survive, and experience an evolving survival game prototype built using Three.js.

## 🚀 Getting Started

Before jumping into the game, you'll need to import the 3D models.

1. Launch the game.
2. Open **Settings** from the main menu.
3. Locate the **Models Folder** option.
4. Select the `Models` folder from the project directory.
5. Once the models are imported, return to the game and start playing!

> **Important:** Make sure you select the correct `Models` folder so the game can locate and load its 3D assets properly.
